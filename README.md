本地运行的 Streamlit 小应用：同步 / 导入中国福利彩票「快乐8」**公开开奖数据**，查看号码频次与遗漏统计，汇总公开视频评论中的号码提及，并为「选一」～「选十」各生成一组**随机参考号码**及其理论概率。

> [!IMPORTANT]
> **这不是预测器。** 快乐8 每期开奖相互独立、完全随机，历史频率、遗漏值和网友观点都不能可靠预测下一期。本项目的一切输出仅为**描述性统计与透明的随机数实验**，不构成任何投注建议，也不存在「保底」「必中」。
> 未满 **18 周岁**人士请勿购买彩票。彩票有风险，请理性参与。本仓库及作者**不提供**任何代购、预测或付费选号服务。

## 功能特性

- **数据同步**：从中国福彩官方公开接口同步最近开奖，支持分页自动补齐历史；也可按页抓取彩经网开奖列表（每页 30 期，导出与导入一致的宽表 CSV）；站点不可用时支持 CSV / TSV / XLSX 导入。
- **本地存储**：SQLite 保存期号、日期与开奖号码，**数据不出本机**，不上传任何服务器。
- **统计面板**：最近期次、号码出现次数、当前遗漏期数、手动评论号码提及次数等描述性统计。
- **随机参考组合**：选一至选十各生成一组 1–80 不放回随机抽样号码，并显示「n 个全中」的理论概率，可导出 CSV。
- **公开评论汇总**：一键获取抖音 / B站视频公开评论（B站公开接口优先，抖音用本机浏览器**被动监听**），也可手动粘贴文本；只在当前会话汇总号码，不保存评论原文与账号信息。
- **智能提取器**：支持阿拉伯数字、中文数字（二十三、廿五）、Emoji 序号（①、3️⃣）与连写拆分（01082379 → 01/08/23/79），自动过滤日期、时间、金额等干扰。

## 快速开始

建议 Python 3.10 或更高版本。

```bash
cd happy8_reference
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

应用默认在本机浏览器打开。数据库文件 `happy8.sqlite3` 首次运行时自动创建（已加入 `.gitignore`，不会进入仓库）。

## 开奖数据来源与采集原则

- 中国福彩网快乐8规则页：<https://www.cwl.gov.cn/fcpz/yxjs/kl8/>
- 使用的官方公开查询接口：<https://www.cwl.gov.cn/cwl_admin/front/cwlkj/search/kjxx/findDrawNotice?name=kl8>
- 彩经网开奖列表（静态页面）：<https://www.cjcp.cn/kl8kaijiang/>

采集原则：只发起普通 HTTPS 请求；**不使用登录 Cookie、不绕过访问控制、不高频轮询**；批量同步时自动分页并随机间隔。接口可能受站点维护或策略调整影响而失效，此时请稍后重试或改用 CSV 导入，以官方渠道数据为准。

## 导入格式

支持 CSV、TSV（含 Excel「Unicode 文本」UTF-16 导出）与 XLSX。程序自动识别逗号 / 制表符 / 分号 / 竖线分隔，并在前 20 行查找表头。XLSX 需包含 `期号`、`开奖日期`、`号码1`…`号码20` 列，多余列忽略。每期必须恰有 20 个不重复号码，范围 1–80。

紧凑格式示例：

```csv
issue,date,numbers
2026001,2026-01-01,"01 03 05 08 12 17 21 24 29 31 35 38 42 47 51 56 63 69 74 80"
```

也支持 `issue,date,n1,...,n20`（及 `num1..num20` / `red1..red20`）宽表列名。

## 评论与观点的处理

- **自动获取**：粘贴一个或多个视频链接 / ID（换行或逗号分隔，多目标自动合并去重）。B站优先走公开接口；抖音或接口失败时改用本机浏览器监听（DrissionPage，方案见《我的中奖梦.py》）：使用你本机已登录的浏览器正常打开页面，**被动读取浏览器已收到的评论数据包**——不破解签名、不绕过验证、不自动登录。
- **手动粘贴**：每行一条，作为兜底。
- 提取器每行每号最多计一次；原始评论**不写入数据库**（如需留存请自行导出 CSV）。请勿采集或留存他人账号、私信、手机号等个人信息，并遵守对应平台规则与适用法律。

## 选号与概率

每个玩法从 1–80 不放回抽取 n 个号码。对一组固定的 n 个号码，若目标为「n 个全中」，理论概率为：

```text
C(20, n) / C(80, n)
```

每期从 80 个号码中开出 20 个。显示的概率是组合数学计算结果，**不是奖金承诺**；奖级、奖金与派奖以官方当期公告为准。
